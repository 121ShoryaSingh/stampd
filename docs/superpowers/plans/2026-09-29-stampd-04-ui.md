# Stampd Plan UI: Design System, App Screens and Landing Page

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Turn the working screens into a polished, consistent Neo-Brutalist product: a real component kit, a responsive app shell with logout, a richer dashboard, a visual envelope page, refined editor and signer screens, tasteful motion, and the approved marketing landing page, with automated accessibility checks.

**Architecture:** A small component kit in `src/components/ui/*` (no UI framework; Tailwind v4 tokens already exist). App pages are rebuilt on the kit without changing server logic. GSAP is used only on marketing pages (installed from npm, loaded in client components). App motion is CSS-only and disabled under `prefers-reduced-motion`. Accessibility is enforced by `@axe-core/playwright` in e2e.

**Tech Stack:** existing stack + `lucide-react` (icons), `gsap` + `@gsap/react` (marketing only), `@axe-core/playwright` (dev).

**Spec:** `docs/superpowers/specs/2026-09-28-stampd-design.md` section 8 (UI), and the approved landing mockup (option D, Neo-Brutalist, GSAP). This plan runs before Plan 4 (email, worker, sealing, deploy) at the user's request.

## Global Constraints

- All earlier constraints apply (Prisma only, no raw SQL in app code, ASCII, short one-line comments, "Enter <label>" placeholders).
- Design language: white paper, black ink, 2.5 px borders, hard offset shadows, 0 px radius; accents yellow `#FFE600`, red `#FF3D00`, pink `#FF8AD8`, green `#00D26A`, blue `#2F5BFF`; fonts Archivo Black (display), Space Grotesk (UI), JetBrains Mono (labels/data).
- Motion: CSS only in the app, 120-300 ms, `cubic-bezier(.2,.8,.2,1)`; all animation off under `prefers-reduced-motion: reduce`. GSAP only under `src/app/(marketing)`.
- Every interactive element has an accessible name; color is never the only signal (status pills carry text); focus is always visible (2 px red outline, offset 2 px).
- Mobile first: every app and signer page works at 375 px width without horizontal scroll.
- Marketing placeholder stats, logos and reviews stay visibly labelled "placeholder" until real data exists (FTC / EU / UK rules on fake reviews).
- Existing e2e selectors (labels, button names, test ids) keep working, or tests are updated in the same task.

## Review Focus

1. Keyboard-only use: every flow (login, create, upload, edit fields, send, sign) must be doable without a mouse; modals trap focus and close on Escape. Pinned in Task 1 (Modal tests) and Task 8 (axe + keyboard e2e).
2. Small screens: the sidebar collapses behind a menu button at < 768 px; no page scrolls sideways at 375 px. Pinned in Task 2 and Task 8.
3. Reduced motion: with `prefers-reduced-motion`, nothing animates (including GSAP). Pinned in Task 6 and Task 7.
4. Logging out actually ends the session (back button does not show the dashboard). Pinned in Task 2.
5. Empty, loading and error states exist for every list (no blank screens). Pinned in Tasks 3-4.

### Task 1: Component kit

**Files:** `src/components/ui/{button,input,textarea,select,checkbox,badge,modal,toast,empty-state,skeleton,page-header,stat-tile,table,icon-button}.tsx`, `src/app/globals.css` (motion tokens, focus ring, keyframes), tests `src/components/ui/*.test.tsx`.

**Interfaces (produced):**
- `Button({ variant?: "default"|"primary"|"accent"|"ghost"|"danger", size?: "sm"|"md"|"lg", loading?: boolean, icon?: ReactNode })` (loading disables and shows a spinner; keeps accessible name)
- `Input({ label, hint?, error? })` (error sets `aria-invalid` and `aria-describedby`), `Textarea`, `Select`, `Checkbox({ label })`
- `Badge({ tone, children })`; `StatusPill` re-implemented on Badge with an icon per status
- `Modal({ open, onClose, title, children, footer? })`: portal, focus trap, Escape and backdrop close, returns focus to the opener, `role="dialog" aria-modal`
- `ToastProvider`, `useToast(): { show(message, tone?) }` (aria-live polite region, auto-dismiss 4 s)
- `EmptyState({ title, body, action? })`, `Skeleton({ className })`, `PageHeader({ title, subtitle?, actions? })`, `StatTile({ label, value, hint?, tone? })`, `Table` primitives (`Table`, `THead`, `TRow`, `TCell`)

- [ ] Implement; `npm test` green; commit `feat: ui component kit`.
